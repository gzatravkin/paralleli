# ПАРАЛЛЕЛИ

Прототип для геймджема: метроидвания про параллельные миры.

Карта одна и та же, но у неё **27 версий** по трём осям — температура (мороз/норма/жара),
увядание (тлен/норма/буйство) и эпоха (прошлое/настоящее/будущее). Дверь переносит
в ту же точку карты, но в соседнюю версию мира. Вернуться той же дверью нельзя:
дверь существует только при одном значении своей оси.

Игрок собирает 4 части разбитого девайса. Часть открывает ось целиком, а ось — это пара
дверей. Части «суперстабильны»: лежат в одной точке во всех мирах, видны всегда, но
дотянуться до них можно не из каждой версии.

**Играть: https://gzatravkin.github.io/paralleli/**

Управление: `A`/`D` идти, `W`/пробел прыжок, `W`/`S` по лианам, `E` войти в дверь,
`R` заново, `TAB` карта миров.

Под игрой выводится аудит уровня — перебор по пространству (клетка × версия мира ×
набор частей): решается ли уровень, есть ли тупики, сколько существует разных маршрутов.
